# Pet Profile Content Design

## Overview

Add dynamic content to Jaffe's (pet dog) profile page: dog fun facts, animal jokes, and rotating AI-generated media. Content is generated by Claude and stored in Supabase, with an admin UI to regenerate.

## Database Schema

New table `pet_content`:

```sql
create table pet_content (
  id uuid primary key default gen_random_uuid(),
  type text not null check (type in ('fact', 'joke')),
  content text not null,
  created_at timestamp with time zone default now()
);
```

- `type`: Either 'fact' or 'joke'
- Full replace on regeneration (delete all, insert new batch)
- 50 facts + 50 jokes per generation

## API Routes

### GET `/api/pet-content`

Fetches one random fact and one random joke.

```typescript
// Response
{ fact: string, joke: string }
```

Uses Supabase random ordering with limit 1 for each type.

### POST `/api/admin/pet-content/generate`

Protected admin endpoint. Calls Claude to generate 50 dog facts and 50 animal jokes in a single request. Deletes existing content, inserts new batch.

```typescript
// Response
{ success: true, facts: 50, jokes: 50 }
```

## Profile Page Components

### PetFactCard

- Icon: `Lightbulb`
- Label: "Fun Fact"
- Fetches from `/api/pet-content` on mount
- Skeleton loader while loading

### PetJokeCard

- Icon: `Smile`
- Label: "Joke"
- Same fetch as PetFactCard (single API call)
- Skeleton loader while loading

Layout: Side by side in 2-column grid, after profile header.

### PetMediaCard

- Full-width card below fact/joke cards
- Randomly displays one of 6 media items on each load
- Images: Next.js `<Image>` with optimization
- Videos: `<video>` muted autoplay loop (GIF-like)

## Admin UI

New section in `/admin` page:

- Header: "Pet Content"
- Stats display: current fact/joke counts
- "Regenerate Content" button with confirmation dialog
- Loading state during generation (~10-15 seconds)
- Success toast on completion

## Component Rendering Logic

Cards only render when `avatarInfo?.role === 'pet'` on the profile page.
